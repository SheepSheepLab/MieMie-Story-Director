# 0.1.5 默认提示词

本次按 Owner 提供的原文更新产品默认配置，不改变请求构造、预设规划读取、宏替换、过滤或 story_scene 交接算法。内容定义在 `src/default-prompts.js`，冻结 0.1.22 Core 与业务 Runtime 保持原样。

| 库 | 默认条目顺序 | 初始状态 |
| --- | --- | --- |
| 导演规划 | 空 | 无条目 |
| 最高指令 | 禁止-默认 → 大纲输出提示词-默认 | 两条均开启 |
| 主 API 提示词 | 思维链-默认 | 开启 |

三条内置默认固定在各自库底部，顺序不可改变。名称／内容字段只读，仍可滚动、选择、复制；单条导出可用，删除置灰。可以自由开关；自定义时关闭默认并新建条目，恢复时再次启用默认。新建与导入仍沿用原库的顶部插入行为，自建条目互相排序、编辑、删除不受影响。

产品入口通过 `withDefaultPrompts` 包装本扩展的配置读取。其他命名空间原样委托，启动不会主动覆写存储。无历史数组时使用新默认；旧默认名称和内容精确匹配时更新原文，保留开关；已修改的旧默认保留为普通 DIY，冲突 ID 自动避让。已有数组中的其他条目维持顺序和内容，缺失默认补为关闭状态；默认置于尾部并使用固定顺序。已有导演规划保持原样。

`src/ui/default-prompt-protection.js` 仅由产品入口启用：只读字段与操作拦截保护默认，阻止拖拽、触控及键盘移动默认，亦阻止 DIY 排序越过默认边界。生命周期资源负责解绑与观察器清理。历史比较工厂不启用产品默认层，因此冻结行为、golden 和 fixture 可持续校验。

宏替换仍走既有预设流程：`<user>` 与 `{{getvar::…}}` 在实际主／副请求中展开，wrapper 和上下文位置不变。默认文字是 Owner 作者内容，格式与字数要求的实际执行效果取决于所用模型；本轮离线测试不代表服务商输出已验收。

验证记录与单脚本产物见 `review/prompt-defaults-0.1.5/` 和 `build/`。没有公开发布、更新远端或修改其他工具。
